1 call: P(slow)=1%  |  10 calls: 1-0.9910=9.6%  |  100 calls: 1-0.99100=63.4%

5 microservices in series, each P99=99% fast → composed P99 = 0.99⁵ = 95.1%. End-to-end is worse than any single hop — measure the whole chain.

Root Cause 1

GC pauses — invisible at P50, brutal at P99

Minor GC
1–5ms
P50 unaffected
Major GC
50ms–2s
stops all threads

P50: 10ms (untouched)  →  P99: 800ms (~1 in 100 requests caught mid-collection).

Fix: tune G1GC (MaxGCPauseMillis=100), pre-allocate heap (-Xms=-Xmx), or move to ZGC/Shenandoah for sub-10ms pauses.

Root Cause 2

Hot / lagging replica

Replica 1
lag 0ms · 15ms
Replica 2
lag 0ms · 18ms
Replica 3
lag 2s · 2100ms

Load balancer sends 33% of reads to each replica → 33% of reads silently hit the 2.1s slow follower.

Fix: health-check replicas on lag, exclude lagging nodes from the read pool.

Root Causes 3, 4, 5

Thread pools, network jitter, hot rows

Tomcat Pool

TCP Retransmit
0.01% loss
+200ms–1s (P99.9)

Thread pool: 150/200 busy → request 201 queues → P99 = 50ms + 50ms queue + 50ms exec = 150ms.

Lock contention: 10 writes to same row, thread 10 waits 45ms behind 9 locks → that row's P99 = 50ms vs 5ms elsewhere.

Fix: size pools with Little's Law, add jitter to retries, batch hot-row updates.

The Fix — Google's Technique

Hedged requests

Client
▼
Server A
GC pause → 800ms
Server B
sent at P95=95ms → 110ms

No response by P95 threshold (95ms) → duplicate request to Server B → use whichever replies first.

Result: 800ms → 110ms (7x improvement) for ~1% extra requests on the tail. Used by Google BigTable, Cassandra (speculative execution), AWS S3.

Cheat Sheet

Diagnosis decision tree

1. P99 spikes periodic? → correlate with GC logs

2. Slow by server tag? → check replica lag (pg_stat_replication)

3. Slow under high RPS? → check thread pool / queue depth

4. Slow on one entity ID? → hot row / lock contention

5. Random P99.9 spikes? → network jitter, TCP retransmit

"P99 latency matters more than average — when users make 100 API calls per session, a 1% slow tail means 63% of sessions hit it; measure with histograms, fix with hedging and root-cause tracing."
