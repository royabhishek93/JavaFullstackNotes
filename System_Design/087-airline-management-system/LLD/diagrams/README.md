# Draw.io Diagrams

This folder contains editable architecture diagrams for the system design.

## How to Open

1. **Online**: Go to [diagrams.net](https://app.diagrams.net) → File → Open → select any `.drawio` file
2. **VS Code**: Install the "Draw.io Integration" extension, then click any `.drawio` file
3. **Desktop**: Download [draw.io desktop app](https://github.com/jgraph/drawio-desktop/releases)

## Diagram Types

| File | Purpose |
|------|---------|
| `03-primary-sequence.drawio` | Request flow: step-by-step sequence of main user action |
| `06-class-uml.drawio` | Class diagram: objects, methods, inheritance, composition |
| `07-state-machine.drawio` | State transitions: lifecycle, events, state changes |

## Tips

- All diagrams are **editable** - customize for your interview prep
- Export to PNG/SVG for presentations: File → Export as...
- Use these as templates for other system designs
