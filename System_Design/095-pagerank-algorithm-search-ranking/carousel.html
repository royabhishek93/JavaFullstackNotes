Importance Is Recursive

The Problem

A professor's importance depends on how important their recommenders are — which depends on THEIR recommenders. Circular.

PageRank solves it with power iteration: guess equal scores, recompute based on current scores, repeat until stable.

The Core Formula

The Solution

PR(A) = (1-d)/N + d × Σ[PR(Ti)/C(Ti)]

for every page Ti linking to A. d = damping factor (0.85), N = total pages, C(Ti) = out-degree of Ti.

The Random Surfer

Why Damping Factor = 0.85

85% of the time: follow a link. 15% of the time: teleport to a random page.

This teleport probability is what guarantees convergence instead of an infinite loop.

The Dangling Node Trap

Where PageRank Breaks

A page with ZERO outbound links leaks its "mass" out of the system if skipped — total PageRank drops below 1.0.

Fix: redistribute dangling mass uniformly across ALL nodes each iteration — O(1) correction, not per-edge.

Sparse Matrix at Web Scale

Distributed Computation

50B-page graph: ~1 non-zero entry per billion possible — never a dense matrix.

Computed as MapReduce/Pregel "supersteps": emit score/out-degree → shuffle+reduce sum → check convergence → repeat.

Decision Tree & Interview Answer

Quick Reference

Need recursive, hard-to-game importance? → PageRank. Need real-time per-query ranking? → Personalized PageRank or a learned model instead.
