Hybrid Solution

Skip Fan-Out Above a Threshold

Classify accounts by follower count (100K-1M typical). Above it: post written ONCE to celebrity's own timeline — O(1), no fan-out job at all.

The Threshold Trap

Don't Copy Someone Else's Number

Too low → normal accounts pay unneeded read complexity. Too high → upper-mid-tier accounts still saturate the write path.

Pipelined Writes Matter Too

Implementation Detail

Never one round-trip per follower. Pipelined Redis ZADD batch writes: 200K-400K ops/sec per shard — a 12K-follower fan-out finishes in well under 100ms.

Quick Reference

Long-tail follower distribution with real celebrities? → Hybrid. All accounts roughly similar size? → Pure push is fine.
