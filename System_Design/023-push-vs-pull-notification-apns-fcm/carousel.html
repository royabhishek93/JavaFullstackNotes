Part 3 · Phone Is Offline

Offline delivery: last-wins vs queue

APNs

  • Stores the LAST notification per topic only
  • 5 sends while offline → device wakes to 1
  • apns-expiration controls how long it's held
  • expiration=0 → deliver now or discard, no storage

FCM

  • Stores up to 100 messages per device
  • Default expiration: 4 weeks
  • collapse_key = opt-in last-wins behavior

Set expiration to 24h for chat messages, or to the exact deadline (e.g. flash-sale end) for time-sensitive promos.

Part 4 · Token Hygiene

Token lifecycle & the 410 problem

Token goes invalid when: app uninstalled · phone restored from backup (new token issued) · APNs rotates the token periodically.

  • On 410 Gone: DELETE FROM device_tokens WHERE token=… AND last_updated < ts
  • Skip cleanup → DB bloats with dead tokens → APNs rate-limits you for spamming invalid tokens
  • iOS 13+: tokens rotate periodically for privacy, even without reinstall
  • Best practice: re-register the token on every app launch via didRegisterForRemoteNotificationsWithDeviceToken

Part 5 · Alert vs Silent

Two notification types (WhatsApp-style)

Alert

  • Visible banner, sound, badge
  • User must be reachable
  • apns-push-type: alert

Background / data

  • Silently wakes app in background
  • App fetches data, no banner shown
  • apns-push-type: background, content-available: 1
