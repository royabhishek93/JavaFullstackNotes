5 quadrillion cells

500M users × 10M items. Netflix never asked about your taste — it just noticed thousands of others like you.

The Sparse Matrix

The Problem

User-item interaction matrix: rows=users, cols=items, cells=preference signal. Almost entirely EMPTY — any user touches a tiny slice of the catalog.

User-Based vs Item-Based

Two Ways to Read the Matrix

User-based: find similar users, recommend what THEY liked.

Item-based: find similar items via co-occurrence. Preferred at scale — catalog is more stable than the churning user base.

Matrix Factorization

The Solution

R (users × items) ≈ U (users × k) · I (items × k)ᵀ

k ≈ 100 latent factors. Compresses 5 quadrillion cells → ~51 billion floats (~204GB).

ALS Training Loop

Alternating Least Squares

Fix item vectors → solve user vectors → fix user vectors → solve item vectors → repeat 10-20 iterations until convergence.

Distributed via Spark MLlib, 1-4 hours nightly.

Cold Start

The Trap

New user/item = completely BLANK row/column. Dot product is meaningless.

✓ Fallback: popularity ranking, onboarding genre picks, creator-audience proxy.
