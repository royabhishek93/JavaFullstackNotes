Where This Shows Up

Real Systems & Company Examples

Hotstar-style premiere: 10M+ concurrent viewers. 220 edges × 14.4GB (1,440 HLS segments/edge) = 3.17TB pre-warmed in 15-30 min before kickoff.

Swiggy/Zomato menu images: origin pull + origin shield, targeting >95% cache hit rate on unpredictable long-tail assets.

Flipkart/Myntra flash sale: cache-busted URLs for static assets + explicit purge (~30s propagation) for live pricing pages.

Decision Tree & Interview Answer

Quick Reference

Known viral / scheduled launch? → Origin push, pre-warm all edges. Unpredictable long-tail content? → Origin pull + origin shield. Static assets? → cache-busted URLs, 1-year TTL.

"Origin pull is lazy: CDN fetches from origin on first miss per edge. Origin push is eager: you pre-warm content before users arrive. For a viral movie launch, pre-warm all 220 edge nodes — zero cache misses on launch day. For long-tail content, origin pull with origin shield prevents stampede to your origin."
