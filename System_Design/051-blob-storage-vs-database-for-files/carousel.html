When Is BLOB-in-DB OK?

The Decision Rule

✓ Guaranteed <1KB: icons, tiny base64 thumbnails — row impact negligible

✓ Strict compliance + encryption-at-rest: medical/legal docs, capped <1MB (Postgres bytea)

✕ Any file that could exceed 100KB → object storage, always

Gray zone 1KB–100KB → default to S3 unless there's a strong reason not to.

Decision Tree & Interview Answer

Quick Reference

File could be >100KB? → S3, always. Guaranteed <1KB? → DB is fine. Private + compliance-bound? → S3 presigned URLs (or encrypted bytea if audited).

"Store S3 key in DB, bytes in S3. A 2MB BLOB in MySQL corrupts the buffer pool, bloats the binary log, and forces every image request through your API server. S3 + CDN serves images directly to browsers — zero API server load, zero DB impact."
