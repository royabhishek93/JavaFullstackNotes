CLOSED — Normal Operation

State 1

CLOSED

Requests flow through normally. Circuit breaker silently counts failures in the background.

5 failures in 60s → trip to OPEN.

OPEN — Tripped

State 2

OPEN

Every request fails instantly — no call attempted, no thread blocked. Order processing continues normally.

After 30s wait → move to HALF-OPEN.

HALF-OPEN — Recovery Probe

State 3

HALF-OPEN

ONE request allowed through as a test.

✓ Succeeds → circuit CLOSES   ✕ Fails → back to OPEN, wait again

Decision Tree & Interview Answer

Quick Reference

Can the call be async? → Make it async, skip the circuit breaker. Must be synchronous? → Circuit breaker + fallback, always.

"Circuit breaker prevents cascade failure by short-circuiting calls to a failing downstream service. In OPEN state, calls return immediately with a fallback — no threads blocked, no cascade. After a cooldown, one probe request tests recovery."
