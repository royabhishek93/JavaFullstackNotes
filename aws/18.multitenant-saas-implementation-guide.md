### Key Design Principles

1. **Tenant Isolation**: Complete data separation between tenants
2. **Scalability**: Horizontal scaling of application layer
3. **Security**: Defense in depth with multiple layers
4. **Customization**: Per-tenant configuration and branding
5. **Cost Efficiency**: Shared infrastructure with fair resource allocation

## 2. Database Architecture: Platform vs Tenant Databases

### The Two-Database Model

In production multitenant systems, we typically use **two separate database layers**:

```text
┌─────────────────────────────────────────────────────────────────────┐
│                  DATABASE ARCHITECTURE                               │
├─────────────────────────────────────────────────────────────────────┤
│                                                                      │
│  LAYER 1: PLATFORM/PRODUCT DATABASE (Shared Infrastructure)        │
│  ┌──────────────────────────────────────────────────────────────┐  │
│  │  Purpose: System-wide data, not tenant-specific              │  │
│  │  Database: platform_db                                        │  │
│  │                                                                │  │
│  │  Tables:                                                       │  │
│  │  • tenants                - Tenant registry                   │  │
│  │  • subscription_plans     - Pricing tiers                     │  │
│  │  • billing_accounts       - Payment info                      │  │
│  │  • usage_metrics          - Consumption tracking              │  │
│  │  • feature_flags          - Feature toggles per tenant        │  │
│  │  • api_keys               - External API credentials          │  │
│  │  • audit_log              - Cross-tenant audit trail          │  │
│  │  • tenant_config          - Tenant-specific settings          │  │
│  │  • system_users           - Platform admins                   │  │
│  │                                                                │  │
│  │  Characteristics:                                              │  │
│  │  - Small dataset (thousands of rows)                          │  │
│  │  - Read-heavy                                                  │  │
│  │  - Highly cached (Redis)                                      │  │
│  │  - Single database instance                                   │  │
│  └──────────────────────────────────────────────────────────────┘  │
│                                                                      │
│  LAYER 2: TENANT/CONSUMER DATABASES (Business Data)                │
│  ┌──────────────────────────────────────────────────────────────┐  │
│  │  Purpose: Tenant-specific business data                       │  │
│  │                                                                │  │
│  │  Strategy A: Single Shared Database                           │  │
│  │  Database: tenants_db (all tenants)                           │  │
│  │                                                                │  │
│  │  Tables (all have tenant_id):                                 │  │
│  │  • users                  - Tenant users                      │  │
│  │  • products               - Product catalog                   │  │
│  │  • orders                 - Order records                     │  │
│  │  • customers              - Customer records                  │  │
│  │  • invoices               - Billing documents                 │  │
│  │  • documents              - File metadata                     │  │
│  │                                                                │  │
│  │  OR Strategy B: Schema Per Tenant                             │  │
│  │  Database: tenants_db                                         │  │
│  │  Schemas: tenant_a, tenant_b, tenant_c                        │  │
│  │                                                                │  │
│  │  OR Strategy C: Database Per Tenant                           │  │
│  │  Databases: tenant_a_db, tenant_b_db, tenant_c_db             │  │
│  │                                                                │  │
│  │  Characteristics:                                              │  │
│  │  - Large dataset (millions of rows)                           │  │
│  │  - Write-heavy                                                 │  │
│  │  - Needs strong isolation                                     │  │
│  │  - Scaled independently                                       │  │
│  └──────────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────────┘
```

### Platform Database Schema (Product/System Database)

```sql
-- ============================================================================
-- PLATFORM DATABASE: platform_db
-- ============================================================================

-- Tenant Registry: Master list of all tenants
CREATE TABLE tenants (
    tenant_id               VARCHAR(50) PRIMARY KEY,
    tenant_name             VARCHAR(200) NOT NULL,
    subdomain               VARCHAR(100) UNIQUE NOT NULL,
    custom_domain           VARCHAR(200),
    
    -- Subscription
    subscription_plan_id    VARCHAR(50) NOT NULL,
    status                  VARCHAR(30) NOT NULL,  -- ACTIVE, TRIAL, SUSPENDED, CANCELLED
    trial_ends_at           TIMESTAMPTZ,
    subscription_ends_at    TIMESTAMPTZ,
    
    -- Database routing information
    database_strategy       VARCHAR(30) NOT NULL,  -- SHARED, SCHEMA, DEDICATED
    database_host           VARCHAR(200),          -- For dedicated DB strategy
    database_name           VARCHAR(63),           -- For dedicated DB strategy
    schema_name             VARCHAR(63),           -- For schema-per-tenant strategy
    
    -- Limits and quotas
    max_users               INT NOT NULL DEFAULT 10,
    max_storage_gb          INT NOT NULL DEFAULT 5,
    max_api_calls_per_day   INT NOT NULL DEFAULT 10000,
    
    -- Branding
    logo_url                VARCHAR(500),
    primary_color           VARCHAR(7),
    secondary_color         VARCHAR(7),
    
    -- Contact
    admin_email             VARCHAR(255) NOT NULL,
    support_email           VARCHAR(255),
    
    -- Metadata
    created_at              TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at              TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    settings                JSONB,
    
    CONSTRAINT fk_subscription_plan 
        FOREIGN KEY (subscription_plan_id) 
        REFERENCES subscription_plans(plan_id)
);

CREATE INDEX idx_tenants_subdomain ON tenants(subdomain);
CREATE INDEX idx_tenants_status ON tenants(status);
CREATE INDEX idx_tenants_plan ON tenants(subscription_plan_id);

-- Subscription Plans
CREATE TABLE subscription_plans (
    plan_id                 VARCHAR(50) PRIMARY KEY,
    plan_name               VARCHAR(100) NOT NULL,
    tier                    VARCHAR(30) NOT NULL,  -- FREE, BASIC, PREMIUM, ENTERPRISE
    price_monthly           DECIMAL(10, 2) NOT NULL,
    price_yearly            DECIMAL(10, 2) NOT NULL,
    
    -- Limits
    max_users               INT NOT NULL,
    max_storage_gb          INT NOT NULL,
    max_api_calls_per_day   INT NOT NULL,
    
    -- Features
    features                JSONB NOT NULL,        -- {"sso": true, "api_access": true}
    
    -- Metadata
    is_active               BOOLEAN NOT NULL DEFAULT TRUE,
    created_at              TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- Billing Accounts
CREATE TABLE billing_accounts (
    billing_id              VARCHAR(50) PRIMARY KEY,
    tenant_id               VARCHAR(50) NOT NULL,
    
    -- Payment method
    stripe_customer_id      VARCHAR(100),
    payment_method_type     VARCHAR(30),           -- CARD, INVOICE, WIRE
    
    -- Billing contact
    billing_email           VARCHAR(255) NOT NULL,
    company_name            VARCHAR(200),
    tax_id                  VARCHAR(50),
    
    -- Address
    billing_address         JSONB,
    
    -- Status
    status                  VARCHAR(30) NOT NULL,  -- ACTIVE, PAST_DUE, CANCELLED
    next_billing_date       DATE,
    
    created_at              TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    
    FOREIGN KEY (tenant_id) REFERENCES tenants(tenant_id)
);

CREATE INDEX idx_billing_tenant ON billing_accounts(tenant_id);

-- Usage Metrics (for metering and billing)
CREATE TABLE usage_metrics (
    metric_id               BIGSERIAL PRIMARY KEY,
    tenant_id               VARCHAR(50) NOT NULL,
    metric_type             VARCHAR(50) NOT NULL,  -- API_CALLS, STORAGE_GB, USERS
    metric_value            BIGINT NOT NULL,
    recorded_at             TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    billing_period          VARCHAR(7) NOT NULL,   -- YYYY-MM
    
    FOREIGN KEY (tenant_id) REFERENCES tenants(tenant_id)
);

CREATE INDEX idx_usage_tenant_period 
    ON usage_metrics(tenant_id, billing_period, metric_type);

-- Feature Flags (per-tenant feature toggles)
CREATE TABLE feature_flags (
    flag_id                 VARCHAR(50) PRIMARY KEY,
    flag_name               VARCHAR(100) NOT NULL,
    description             TEXT,
    is_global               BOOLEAN NOT NULL DEFAULT FALSE,
    created_at              TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE TABLE tenant_feature_flags (
    tenant_id               VARCHAR(50) NOT NULL,
    flag_id                 VARCHAR(50) NOT NULL,
    is_enabled              BOOLEAN NOT NULL DEFAULT FALSE,
    enabled_at              TIMESTAMPTZ,
    enabled_by              VARCHAR(50),
    
    PRIMARY KEY (tenant_id, flag_id),
    FOREIGN KEY (tenant_id) REFERENCES tenants(tenant_id),
    FOREIGN KEY (flag_id) REFERENCES feature_flags(flag_id)
);

-- API Keys (for external integrations)
CREATE TABLE api_keys (
    key_id                  VARCHAR(50) PRIMARY KEY,
    tenant_id               VARCHAR(50) NOT NULL,
    key_name                VARCHAR(100) NOT NULL,
    key_hash                VARCHAR(64) NOT NULL,      -- SHA-256 hash
    key_prefix              VARCHAR(10) NOT NULL,      -- First 8 chars for display
    
    scopes                  VARCHAR(500)[],             -- ['read:products', 'write:orders']
    
    status                  VARCHAR(30) NOT NULL,       -- ACTIVE, REVOKED
    expires_at              TIMESTAMPTZ,
    last_used_at            TIMESTAMPTZ,
    
    created_by              VARCHAR(50) NOT NULL,
    created_at              TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    
    FOREIGN KEY (tenant_id) REFERENCES tenants(tenant_id)
);

CREATE INDEX idx_api_keys_tenant ON api_keys(tenant_id);
CREATE UNIQUE INDEX idx_api_keys_hash ON api_keys(key_hash);

-- Audit Log (platform-level actions)
CREATE TABLE platform_audit_log (
    audit_id                BIGSERIAL PRIMARY KEY,
    tenant_id               VARCHAR(50),                -- NULL for platform actions
    actor_type              VARCHAR(30) NOT NULL,       -- SYSTEM_ADMIN, TENANT_ADMIN, USER
    actor_id                VARCHAR(50) NOT NULL,
    action                  VARCHAR(100) NOT NULL,      -- TENANT_CREATED, PLAN_UPGRADED
    entity_type             VARCHAR(50),                -- TENANT, BILLING, FEATURE_FLAG
    entity_id               VARCHAR(50),
    changes                 JSONB,                      -- Old and new values
    ip_address              INET,
    user_agent              TEXT,
    created_at              TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_platform_audit_tenant ON platform_audit_log(tenant_id, created_at DESC);
CREATE INDEX idx_platform_audit_action ON platform_audit_log(action, created_at DESC);
```

### Consumer/Tenant Database Schema

## 2. Database Strategies

### Strategy 1: Shared Database + Shared Schema (Recommended for Most Cases)

**Pros:**
- Simple to implement and maintain
- Cost-efficient
- Easy to scale
- Simple migrations

**Cons:**
- Tenant data mixed (requires strong filtering)
- Potential noisy neighbor issues
- Complex backup/restore per tenant

```sql
-- Example Schema: Shared Database + Shared Schema

CREATE TABLE tenants (
    tenant_id           VARCHAR(50) PRIMARY KEY,
    tenant_name         VARCHAR(200) NOT NULL,
    subdomain           VARCHAR(100) UNIQUE NOT NULL,
    tier                VARCHAR(30) NOT NULL,  -- FREE, BASIC, PREMIUM, ENTERPRISE
    status              VARCHAR(30) NOT NULL,  -- ACTIVE, SUSPENDED, TRIAL
    max_users           INT NOT NULL DEFAULT 10,
    storage_quota_gb    INT NOT NULL DEFAULT 5,
    custom_domain       VARCHAR(200),
    logo_url            VARCHAR(500),
    primary_color       VARCHAR(7),            -- Hex color
    created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    trial_ends_at       TIMESTAMPTZ,
    settings            JSONB                  -- Flexible config
);

CREATE TABLE users (
    user_id             VARCHAR(50) PRIMARY KEY,
    tenant_id           VARCHAR(50) NOT NULL,
    email               VARCHAR(255) NOT NULL,
    first_name          VARCHAR(100),
    last_name           VARCHAR(100),
    role                VARCHAR(30) NOT NULL,  -- ADMIN, USER, VIEWER
    status              VARCHAR(30) NOT NULL,  -- ACTIVE, INACTIVE, INVITED
    last_login_at       TIMESTAMPTZ,
    created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    
    FOREIGN KEY (tenant_id) REFERENCES tenants(tenant_id),
    UNIQUE (tenant_id, email)
);

-- Critical: Composite index for tenant isolation
CREATE INDEX idx_users_tenant ON users(tenant_id, user_id);
CREATE INDEX idx_users_tenant_email ON users(tenant_id, email);

CREATE TABLE products (
    product_id          VARCHAR(50) PRIMARY KEY,
    tenant_id           VARCHAR(50) NOT NULL,
    name                VARCHAR(200) NOT NULL,
    description         TEXT,
    price               DECIMAL(10, 2) NOT NULL,
    currency            VARCHAR(3) NOT NULL DEFAULT 'USD',
    status              VARCHAR(30) NOT NULL,
    created_by          VARCHAR(50) NOT NULL,
    created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    
    FOREIGN KEY (tenant_id) REFERENCES tenants(tenant_id),
    FOREIGN KEY (tenant_id, created_by) REFERENCES users(tenant_id, user_id)
);

CREATE INDEX idx_products_tenant ON products(tenant_id, created_at DESC);
CREATE INDEX idx_products_tenant_status ON products(tenant_id, status);

CREATE TABLE orders (
    order_id            VARCHAR(50) PRIMARY KEY,
    tenant_id           VARCHAR(50) NOT NULL,
    customer_id         VARCHAR(50) NOT NULL,
    total_amount        DECIMAL(10, 2) NOT NULL,
    status              VARCHAR(30) NOT NULL,
    created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    
    FOREIGN KEY (tenant_id) REFERENCES tenants(tenant_id)
);

CREATE INDEX idx_orders_tenant ON orders(tenant_id, created_at DESC);

-- Row-Level Security (PostgreSQL)
ALTER TABLE products ENABLE ROW LEVEL SECURITY;

CREATE POLICY tenant_isolation_policy ON products
    USING (tenant_id = current_setting('app.current_tenant')::VARCHAR);

-- To use: SET app.current_tenant = 'tenant-123';
```

### Consumer Database: Complete Schema

```sql
-- ============================================================================
-- CONSUMER/TENANT DATABASE: tenants_db
-- All tables below include tenant_id for isolation
-- ============================================================================

-- Users (tenant employees/members)
CREATE TABLE users (
    user_id                 VARCHAR(50) PRIMARY KEY,
    tenant_id               VARCHAR(50) NOT NULL,
    
    -- Identity
    email                   VARCHAR(255) NOT NULL,
    cognito_sub             VARCHAR(50) UNIQUE,        -- AWS Cognito user ID
    first_name              VARCHAR(100),
    last_name               VARCHAR(100),
    
    -- Authorization
    role                    VARCHAR(30) NOT NULL,      -- ADMIN, USER, VIEWER
    permissions             VARCHAR(50)[],              -- Granular permissions
    
    -- Status
    status                  VARCHAR(30) NOT NULL,      -- ACTIVE, INACTIVE, INVITED
    invited_at              TIMESTAMPTZ,
    activated_at            TIMESTAMPTZ,
    last_login_at           TIMESTAMPTZ,
    
    -- Metadata
    created_at              TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at              TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    settings                JSONB,
    
    UNIQUE (tenant_id, email)
);

CREATE INDEX idx_users_tenant ON users(tenant_id, user_id);
CREATE INDEX idx_users_tenant_email ON users(tenant_id, email);
CREATE INDEX idx_users_tenant_status ON users(tenant_id, status);

-- Products
CREATE TABLE products (
    product_id              VARCHAR(50) PRIMARY KEY,
    tenant_id               VARCHAR(50) NOT NULL,
    
    -- Basic info
    name                    VARCHAR(200) NOT NULL,
    sku                     VARCHAR(100),
    description             TEXT,
    
    -- Pricing
    price                   DECIMAL(10, 2) NOT NULL,
    currency                VARCHAR(3) NOT NULL DEFAULT 'USD',
    cost                    DECIMAL(10, 2),            -- For margin calculation
    
    -- Inventory
    stock_quantity          INT NOT NULL DEFAULT 0,
    low_stock_threshold     INT NOT NULL DEFAULT 10,
    
    -- Categorization
    category                VARCHAR(100),
    tags                    VARCHAR(50)[],
    
    -- Status
    status                  VARCHAR(30) NOT NULL,      -- ACTIVE, INACTIVE, ARCHIVED
    
    -- Metadata
    created_by              VARCHAR(50) NOT NULL,
    created_at              TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at              TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    attributes              JSONB,                     -- Custom fields
    
    CONSTRAINT fk_products_created_by 
        FOREIGN KEY (tenant_id, created_by) 
        REFERENCES users(tenant_id, user_id)
);

CREATE INDEX idx_products_tenant ON products(tenant_id, created_at DESC);
CREATE INDEX idx_products_tenant_status ON products(tenant_id, status);
CREATE INDEX idx_products_tenant_sku ON products(tenant_id, sku);
CREATE INDEX idx_products_tenant_category ON products(tenant_id, category);

-- Customers (end customers of the tenant)
```

```java
@Service
public class DataSourceRouter {
    
    private final Map<String, DataSource> tenantDataSources = new ConcurrentHashMap<>();
    private final DataSource platformDataSource;
    private final TenantRepository tenantRepository;
    
    public DataSource getDataSource(String tenantId) {
        // Check cache first
        if (tenantDataSources.containsKey(tenantId)) {
            return tenantDataSources.get(tenantId);
        }
        
        // Query platform DB for tenant's database info
        Tenant tenant = tenantRepository.findById(tenantId)
            .orElseThrow(() -> new IllegalArgumentException("Tenant not found"));
        
        DataSource dataSource;
        
        switch (tenant.getDatabaseStrategy()) {
            case SHARED:
                // Use shared database
                dataSource = platformDataSource;
                break;
                
            case DEDICATED:
                // Create connection to dedicated database
                dataSource = createDataSource(
                    tenant.getDatabaseHost(),
                    tenant.getDatabaseName(),
                    tenant.getDatabaseUsername(),
                    tenant.getDatabasePassword()
                );
                break;
                
            default:
                throw new IllegalStateException("Unknown database strategy");
        }
        
        tenantDataSources.put(tenantId, dataSource);
        return dataSource;
    }
    
    private DataSource createDataSource(String host, String dbName, 
                                       String username, String password) {
        HikariConfig config = new HikariConfig();
        config.setJdbcUrl("jdbc:postgresql://" + host + ":5432/" + dbName);
        config.setUsername(username);
        config.setPassword(password);
        config.setMaximumPoolSize(10);
        config.setMinimumIdle(2);
        
        return new HikariDataSource(config);
    }
}
```

```java
package com.example.saas.security;

import org.springframework.stereotype.Component;

/**
 * Thread-local storage for current tenant context
 * CRITICAL: Must be cleared after each request to prevent leaks
 */
@Component
public class TenantContextHolder {
    
    private static final ThreadLocal<String> TENANT_ID = new InheritableThreadLocal<>();
    
    public static void setTenantId(String tenantId) {
        if (tenantId == null || tenantId.trim().isEmpty()) {
            throw new IllegalArgumentException("Tenant ID cannot be null or empty");
        }
        TENANT_ID.set(tenantId);
    }
    
    public static String getTenantId() {
        String tenantId = TENANT_ID.get();
        if (tenantId == null) {
            throw new IllegalStateException("Tenant context not set");
        }
        return tenantId;
    }
    
    public static void clear() {
        TENANT_ID.remove();
    }
    
    public static boolean isSet() {
        return TENANT_ID.get() != null;
    }
}
```

#### 2. JWT Authentication Filter

```java
package com.example.saas.security;

import io.jsonwebtoken.Claims;
import io.jsonwebtoken.Jwts;
import jakarta.servlet.FilterChain;
import jakarta.servlet.ServletException;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import lombok.extern.slf4j.Slf4j;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.security.authentication.UsernamePasswordAuthenticationToken;
import org.springframework.security.core.authority.SimpleGrantedAuthority;
import org.springframework.security.core.context.SecurityContextHolder;
import org.springframework.stereotype.Component;
import org.springframework.web.filter.OncePerRequestFilter;

import java.io.IOException;
import java.util.List;
import java.util.stream.Collectors;

@Slf4j
@Component
public class JwtAuthenticationFilter extends OncePerRequestFilter {
    
    @Value("${jwt.secret}")
    private String jwtSecret;
    
    @Override
    protected void doFilterInternal(HttpServletRequest request, 
                                    HttpServletResponse response, 
                                    FilterChain filterChain) 
            throws ServletException, IOException {
        
        try {
            String token = extractToken(request);
            
            if (token != null) {
                Claims claims = Jwts.parserBuilder()
                    .setSigningKey(jwtSecret)
                    .build()
                    .parseClaimsJws(token)
                    .getBody();
                
                // Extract tenant ID from JWT claims
                String tenantId = claims.get("tenant_id", String.class);
                String userId = claims.getSubject();
                List<String> roles = claims.get("roles", List.class);
                
                if (tenantId == null) {
                    log.error("JWT token missing tenant_id claim");
                    response.sendError(HttpServletResponse.SC_UNAUTHORIZED, 
                                       "Invalid token: missing tenant");
                    return;
                }
                
                // Set tenant context for this request
                TenantContextHolder.setTenantId(tenantId);
                
                // Set Spring Security authentication
                var authorities = roles.stream()
                    .map(SimpleGrantedAuthority::new)
                    .collect(Collectors.toList());
                
                var authentication = new UsernamePasswordAuthenticationToken(
                    userId, null, authorities);
                
                SecurityContextHolder.getContext().setAuthentication(authentication);
                
                log.debug("Authenticated user {} for tenant {}", userId, tenantId);
            }
            
            filterChain.doFilter(request, response);
            
        } catch (Exception e) {
            log.error("Authentication error", e);
            response.sendError(HttpServletResponse.SC_UNAUTHORIZED, 
                               "Authentication failed");
        } finally {
            // CRITICAL: Clear tenant context to prevent leaks
            TenantContextHolder.clear();
        }
    }
    
    private String extractToken(HttpServletRequest request) {
        String bearerToken = request.getHeader("Authorization");
        if (bearerToken != null && bearerToken.startsWith("Bearer ")) {
            return bearerToken.substring(7);
        }
        return null;
    }
}
```

```java
package com.example.saas.service;

import com.example.saas.model.Product;
import com.example.saas.repository.ProductRepository;
import com.example.saas.security.TenantContextHolder;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.util.List;
import java.util.UUID;

@Slf4j
@Service
@RequiredArgsConstructor
@Transactional
public class ProductService {
    
    private final ProductRepository productRepository;
    private final TenantService tenantService;
    
    public Product createProduct(Product product) {
        String tenantId = TenantContextHolder.getTenantId();
        
        // Validate tenant is active
        if (!tenantService.isTenantActive(tenantId)) {
            throw new IllegalStateException("Tenant is not active");
        }
        
        // Set tenant ID
        product.setTenantId(tenantId);
        product.setProductId(UUID.randomUUID().toString());
        
        log.info("Creating product {} for tenant {}", product.getName(), tenantId);
        return productRepository.save(product);
    }
    
    public List<Product> getAllProducts() {
        String tenantId = TenantContextHolder.getTenantId();
        log.debug("Fetching all products for tenant {}", tenantId);
        
        // Tenant filter automatically applied by JPA
        return productRepository.findAll();
    }
    
    public Product getProduct(String productId) {
        String tenantId = TenantContextHolder.getTenantId();
        
        return productRepository.findById(productId)
            .orElseThrow(() -> new IllegalArgumentException("Product not found"));
        
        // Tenant filter ensures we only get products for current tenant
    }
    
    public void deleteProduct(String productId) {
        String tenantId = TenantContextHolder.getTenantId();
        
        Product product = getProduct(productId);
        
        // Double-check tenant ownership (defense in depth)
        if (!product.getTenantId().equals(tenantId)) {
            throw new SecurityException("Unauthorized access to product");
        }
        
        log.info("Deleting product {} for tenant {}", productId, tenantId);
        productRepository.delete(product);
    }
}
```

```java
package com.example.saas.service;

import com.amazonaws.services.cognitoidp.AWSCognitoIdentityProvider;
import com.amazonaws.services.cognitoidp.model.*;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Service;

import java.util.HashMap;
import java.util.Map;

@Slf4j
@Service
@RequiredArgsConstructor
public class CognitoAuthService {
    
    private final AWSCognitoIdentityProvider cognitoClient;
    
    @Value("${aws.cognito.user-pool-id}")
    private String userPoolId;
    
    @Value("${aws.cognito.client-id}")
    private String clientId;
    
    /**
     * Register new user with tenant context
     */
    public String registerUser(String email, String password, 
                               String tenantId, String role) {
        try {
            AdminCreateUserRequest request = new AdminCreateUserRequest()
                .withUserPoolId(userPoolId)
                .withUsername(email)
                .withTemporaryPassword(password)
                .withUserAttributes(
                    new AttributeType()
                        .withName("email")
                        .withValue(email),
                    new AttributeType()
                        .withName("email_verified")
                        .withValue("true"),
                    new AttributeType()
                        .withName("custom:tenant_id")
                        .withValue(tenantId),
                    new AttributeType()
                        .withName("custom:role")
                        .withValue(role)
                )
                .withDesiredDeliveryMediums(DeliveryMediumType.EMAIL)
                .withMessageAction(MessageActionType.SUPPRESS); // Don't send welcome email
            
            AdminCreateUserResult result = cognitoClient.adminCreateUser(request);
            
            String userId = result.getUser().getUsername();
            log.info("Created Cognito user {} for tenant {}", userId, tenantId);
            
            return userId;
            
        } catch (UsernameExistsException e) {
            throw new IllegalArgumentException("User already exists");
        } catch (Exception e) {
            log.error("Failed to create Cognito user", e);
            throw new RuntimeException("User registration failed", e);
        }
    }
    
    /**
     * Authenticate user and get JWT tokens
     */
    public AuthenticationResult authenticate(String email, String password) {
        try {
            Map<String, String> authParams = new HashMap<>();
            authParams.put("USERNAME", email);
            authParams.put("PASSWORD", password);
            
            AdminInitiateAuthRequest request = new AdminInitiateAuthRequest()
                .withUserPoolId(userPoolId)
                .withClientId(clientId)
                .withAuthFlow(AuthFlowType.ADMIN_NO_SRP_AUTH)
                .withAuthParameters(authParams);
            
            AdminInitiateAuthResult result = cognitoClient.adminInitiateAuth(request);
            
            return result.getAuthenticationResult();
            
        } catch (NotAuthorizedException e) {
            throw new IllegalArgumentException("Invalid credentials");
        } catch (Exception e) {
            log.error("Authentication failed", e);
            throw new RuntimeException("Authentication failed", e);
        }
    }
    
    /**
     * Get user attributes including tenant_id
     */
    public Map<String, String> getUserAttributes(String accessToken) {
        try {
            GetUserRequest request = new GetUserRequest()
                .withAccessToken(accessToken);
            
            GetUserResult result = cognitoClient.getUser(request);
            
            Map<String, String> attributes = new HashMap<>();
            for (AttributeType attr : result.getUserAttributes()) {
                attributes.put(attr.getName(), attr.getValue());
            }
            
            return attributes;
            
        } catch (Exception e) {
            log.error("Failed to get user attributes", e);
            throw new RuntimeException("Failed to get user info", e);
        }
    }
    
    /**
     * Update user's tenant or role
     */
    public void updateUserAttributes(String userId, String tenantId, String role) {
        try {
            AdminUpdateUserAttributesRequest request = new AdminUpdateUserAttributesRequest()
                .withUserPoolId(userPoolId)
                .withUsername(userId)
                .withUserAttributes(
                    new AttributeType()
                        .withName("custom:tenant_id")
                        .withValue(tenantId),
                    new AttributeType()
                        .withName("custom:role")
                        .withValue(role)
                );
            
            cognitoClient.adminUpdateUserAttributes(request);
            
            log.info("Updated user {} attributes", userId);
            
        } catch (Exception e) {
            log.error("Failed to update user attributes", e);
            throw new RuntimeException("Failed to update user", e);
        }
    }
    
    /**
     * Disable user account
     */
    public void disableUser(String userId) {
        try {
            AdminDisableUserRequest request = new AdminDisableUserRequest()
                .withUserPoolId(userPoolId)
                .withUsername(userId);
            
            cognitoClient.adminDisableUser(request);
            
            log.info("Disabled user {}", userId);
            
        } catch (Exception e) {
            log.error("Failed to disable user", e);
            throw new RuntimeException("Failed to disable user", e);
        }
    }
}
```

```typescript
// src/services/api.ts

import axios, { AxiosInstance, AxiosRequestConfig } from 'axios';

class ApiService {
  private axiosInstance: AxiosInstance;
  
  constructor() {
    this.axiosInstance = axios.create({
      baseURL: process.env.REACT_APP_API_URL || 'http://localhost:8080/api/v1',
      timeout: 30000,
      headers: {
        'Content-Type': 'application/json',
      },
    });
    
    // Request interceptor: Add JWT token and tenant context
    this.axiosInstance.interceptors.request.use(
      (config) => {
        const token = localStorage.getItem('access_token');
        const tenantId = localStorage.getItem('tenant_id');
        
        if (token) {
          config.headers.Authorization = `Bearer ${token}`;
        }
        
        if (tenantId) {
          config.headers['X-Tenant-Id'] = tenantId;
        }
        
        console.log('API Request:', config.method?.toUpperCase(), config.url);
        return config;
      },
      (error) => {
        console.error('Request error:', error);
        return Promise.reject(error);
      }
    );
    
    // Response interceptor: Handle errors
    this.axiosInstance.interceptors.response.use(
      (response) => response,
      async (error) => {
        const originalRequest = error.config;
        
        // Handle 401 Unauthorized
        if (error.response?.status === 401 && !originalRequest._retry) {
          originalRequest._retry = true;
          
          // Try to refresh token
          const refreshToken = localStorage.getItem('refresh_token');
          if (refreshToken) {
            try {
              const response = await this.refreshAccessToken(refreshToken);
              localStorage.setItem('access_token', response.data.access_token);
              
              originalRequest.headers.Authorization = `Bearer ${response.data.access_token}`;
              return this.axiosInstance(originalRequest);
            } catch (refreshError) {
              // Refresh failed, logout
              localStorage.clear();
              window.location.href = '/login';
            }
          }
        }
        
        // Handle 403 Forbidden
        if (error.response?.status === 403) {
          console.error('Forbidden: You do not have permission');
        }
        
        // Handle 429 Rate Limit
        if (error.response?.status === 429) {
          console.error('Rate limit exceeded');
        }
        
        return Promise.reject(error);
      }
    );
  }
  
  private async refreshAccessToken(refreshToken: string) {
    return axios.post(`${process.env.REACT_APP_API_URL}/auth/refresh`, {
      refresh_token: refreshToken,
    });
  }
  
  public get<T>(url: string, config?: AxiosRequestConfig) {
    return this.axiosInstance.get<T>(url, config);
  }
  
  public post<T>(url: string, data?: any, config?: AxiosRequestConfig) {
    return this.axiosInstance.post<T>(url, data, config);
  }
```

```typescript
// src/services/authService.ts

import { Auth } from '@aws-amplify/auth';
import { CognitoUser } from 'amazon-cognito-identity-js';

export interface LoginCredentials {

  password: string;
}

export interface RegisterData {

  password: string;

  userId: string;
  email: string;
  tenantId: string;

  lastName?: string;

class AuthService {
  
  async login(credentials: LoginCredentials): Promise<CognitoUser> {
    try {
      const user = await Auth.signIn(credentials.email, credentials.password);
      
      // Extract tokens
      const session = await Auth.currentSession();
      const accessToken = session.getAccessToken().getJwtToken();
      const idToken = session.getIdToken().getJwtToken();
      const refreshToken = session.getRefreshToken().getToken();
      
      // Extract tenant_id from JWT claims
      const payload = session.getIdToken().payload;
      const tenantId = payload['tenant_id'];
      const role = payload['role'] || 'USER';
      
      // Store in localStorage
      localStorage.setItem('access_token', accessToken);
      localStorage.setItem('id_token', idToken);
      localStorage.setItem('refresh_token', refreshToken);
      localStorage.setItem('tenant_id', tenantId);
      localStorage.setItem('role', role);
      
      console.log('Login successful, tenant:', tenantId);
      
      return user;
      
    } catch (error) {
      console.error('Login error:', error);
      throw error;
    }
  }
  
  async register(data: RegisterData): Promise<void> {
    try {
      await Auth.signUp({
        username: data.email,
        password: data.password,
        attributes: {
          email: data.email,
          'custom:tenant_id': data.tenantId,
          'custom:role': 'USER',
          given_name: data.firstName,
          family_name: data.lastName,
        },
      });
      
      console.log('Registration successful');
      
    } catch (error) {
      console.error('Registration error:', error);
      throw error;
    }
  }
  
  async logout(): Promise<void> {
    try {
      await Auth.signOut();
      localStorage.clear();
      console.log('Logout successful');
      
    } catch (error) {
      console.error('Logout error:', error);
      throw error;
    }
  }
  
  async getCurrentUser(): Promise<UserInfo | null> {
    try {
      const session = await Auth.currentSession();
      const payload = session.getIdToken().payload;
      
      return {
        userId: payload.sub,
        email: payload.email,
        tenantId: payload['tenant_id'],
        role: payload['role'] || 'USER',
        firstName: payload.given_name,
        lastName: payload.family_name,
      };
      
    } catch (error) {
      console.error('Get current user error:', error);
      return null;
    }
  }
  
  async refreshSession(): Promise<void> {
    try {
      const session = await Auth.currentSession();
      const accessToken = session.getAccessToken().getJwtToken();
      const idToken = session.getIdToken().getJwtToken();
      
      localStorage.setItem('access_token', accessToken);
      localStorage.setItem('id_token', idToken);
      
    } catch (error) {
      console.error('Refresh session error:', error);
      throw error;
    }
  }
  
  isAuthenticated(): boolean {
    return !!localStorage.getItem('access_token');
  }
  
  getTenantId(): string | null {
    return localStorage.getItem('tenant_id');
  }
  
  getRole(): string | null {

  }
```

```typescript
  isAuthenticated: boolean;
  isLoading: boolean;
  error: string | null;

  user: null,
  isAuthenticated: false,
  isLoading: false,
  error: null,
};

  'auth/login',
  async (credentials: LoginCredentials, { rejectWithValue }) => {
    try {
      await authService.login(credentials);
      const user = await authService.getCurrentUser();
      return user;
    } catch (error: any) {
      return rejectWithValue(error.message);
    }
  }
);

export const logout = createAsyncThunk(
  'auth/logout',
  async () => {
    await authService.logout();
  }
);

export const checkAuth = createAsyncThunk(
  'auth/checkAuth',
  async () => {
    return await authService.getCurrentUser();
  }
);

const authSlice = createSlice({
  name: 'auth',
  initialState,
  reducers: {
    clearError: (state) => {
      state.error = null;
    },
  },
  extraReducers: (builder) => {
    builder
      .addCase(login.pending, (state) => {
        state.isLoading = true;
        state.error = null;
      })
      .addCase(login.fulfilled, (state, action: PayloadAction<UserInfo | null>) => {
        state.isLoading = false;
        state.isAuthenticated = true;
        state.user = action.payload;
      })
      .addCase(login.rejected, (state, action) => {
        state.isLoading = false;
        state.error = action.payload as string;
      })
      .addCase(logout.fulfilled, (state) => {
        state.user = null;
        state.isAuthenticated = false;
      })
      .addCase(checkAuth.fulfilled, (state, action: PayloadAction<UserInfo | null>) => {
        state.isAuthenticated = !!action.payload;
        state.user = action.payload;
      });
  },
});

export const { clearError } = authSlice.actions;
```

```text
│                                                                      │
```

```text
│  ┌──────────────────────────────────────────────────────────────┐  │
│  │  Use Cases:                                                   │  │

│  │  • Validation checks                                          │  │

│  │                                                                │  │
│  │  Pros:                                                         │  │

│  │  • Easy to debug                                              │  │
│  │  • Immediate feedback                                         │  │
│  │                                                                │  │
│  │  Cons:                                                         │  │
│  │  • Timeout issues for long operations                         │  │
│  │  • Resource waste (thread blocking)                           │  │
│  │  • Poor scalability under load                                │  │

│                                                                      │

│  │  • Report generation                                          │  │
│  │  • Data export/import                                         │  │
│  │  • Email sending                                              │  │
│  │                                                                │  │
│  │  Pattern:                                                      │  │

│  │  POST https://customer.com/webhook                            │  │
│  │  → { job_id: "abc-123", status: "COMPLETED" }                 │  │
│  │                                                                │  │
│  │  Pros:                                                         │  │
│  │  • Non-blocking                                               │  │
│  │  • Scales well                                                │  │
│  │  • Reliable (retry mechanisms)                                │  │
│  │  • Better resource utilization                                │  │
│  │                                                                │  │
│  │  Cons:                                                         │  │
│  │  • More complex                                               │  │
│  │  • Requires job tracking                                      │  │
│  │  • Eventual consistency                                       │  │

└─────────────────────────────────────────────────────────────────────┘
```

#### 2. Async Job Service

```java
package com.example.saas.service;

import com.example.saas.model.AsyncJob;
import com.example.saas.repository.AsyncJobRepository;
import com.example.saas.security.TenantContextHolder;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.kafka.core.KafkaTemplate;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.time.Instant;
import java.util.UUID;

@Slf4j
@Service
@RequiredArgsConstructor
public class AsyncJobService {
    
    private final AsyncJobRepository asyncJobRepository;
    private final KafkaTemplate<String, String> kafkaTemplate;
    
    /**
     * Submit an async job
     */
    @Transactional
    public AsyncJob submitJob(String jobType, Object inputParams, String callbackUrl) {
        String tenantId = TenantContextHolder.getTenantId();
        String jobId = UUID.randomUUID().toString();
        
        AsyncJob job = AsyncJob.builder()
            .jobId(jobId)
            .tenantId(tenantId)
            .jobType(jobType)
            .status(AsyncJob.Status.PENDING)
            .inputParams(toJson(inputParams))
            .callbackUrl(callbackUrl)
            .createdAt(Instant.now())
            .build();
        
        asyncJobRepository.save(job);
        
        // Publish to Kafka for async processing
        kafkaTemplate.send("async-jobs", jobId, toJson(job));
        
        log.info("Submitted async job {} of type {} for tenant {}", 
                 jobId, jobType, tenantId);
        
        return job;
    }
    
    /**
     * Get job status
     */
    public AsyncJob getJobStatus(String jobId) {
        String tenantId = TenantContextHolder.getTenantId();
        
        return asyncJobRepository.findByTenantIdAndJobId(tenantId, jobId)
            .orElseThrow(() -> new IllegalArgumentException("Job not found"));
    }
    
    /**
     * Update job progress
     */
    @Transactional
    public void updateProgress(String jobId, int processedItems, int totalItems) {
        AsyncJob job = asyncJobRepository.findById(jobId)
            .orElseThrow(() -> new IllegalArgumentException("Job not found"));
        
        job.setProcessedItems(processedItems);
        job.setTotalItems(totalItems);
        job.setProgressPercentage((processedItems * 100) / totalItems);
        
        asyncJobRepository.save(job);
    }
    
    /**
     * Mark job as completed
     */
    @Transactional
    public void completeJob(String jobId, Object result) {
        AsyncJob job = asyncJobRepository.findById(jobId)
            .orElseThrow(() -> new IllegalArgumentException("Job not found"));
        
        job.setStatus(AsyncJob.Status.COMPLETED);
        job.setResult(toJson(result));
        job.setCompletedAt(Instant.now());
        
        asyncJobRepository.save(job);
        
        // Trigger webhook if configured
        if (job.getCallbackUrl() != null) {
            webhookService.sendJobCompletionWebhook(job);
        }
        
        log.info("Completed job {} for tenant {}", jobId, job.getTenantId());
    }
    
    /**
     * Mark job as failed
     */
    @Transactional
    public void failJob(String jobId, String errorMessage) {
        AsyncJob job = asyncJobRepository.findById(jobId)
            .orElseThrow(() -> new IllegalArgumentException("Job not found"));
        
        job.setRetryCount(job.getRetryCount() + 1);
        
        if (job.getRetryCount() >= job.getMaxRetries()) {
            job.setStatus(AsyncJob.Status.FAILED);
            job.setErrorMessage(errorMessage);
            job.setCompletedAt(Instant.now());
            
            log.error("Job {} failed after {} retries: {}", 
                     jobId, job.getRetryCount(), errorMessage);
        } else {
            job.setStatus(AsyncJob.Status.PENDING);
            
            // Re-publish for retry
            kafkaTemplate.send("async-jobs", jobId, toJson(job));
            
            log.warn("Job {} failed, retry {}/{}", 
                    jobId, job.getRetryCount(), job.getMaxRetries());
        }
        
        asyncJobRepository.save(job);
    }
    
    private String toJson(Object obj) {
        // Jackson serialization
        return JsonUtils.toJson(obj);
    }
}
```

```java
@Component

public class AsyncJobWorker {
    
    private final AsyncJobService asyncJobService;
    private final ProductService productService;
    
    @KafkaListener(topics = "async-jobs", groupId = "job-workers")
    public void processJob(String message) {
        AsyncJob job = JsonUtils.fromJson(message, AsyncJob.class);
        
        try {
            // Set tenant context
            TenantContextHolder.setTenantId(job.getTenantId());
            
            log.info("Processing job {} of type {}", job.getJobId(), job.getJobType());
            
            // Mark as processing
            job.setStatus(AsyncJob.Status.PROCESSING);
            job.setStartedAt(Instant.now());
            asyncJobRepository.save(job);
            
            // Route to appropriate handler
            switch (job.getJobType()) {
                case "BULK_PRODUCT_IMPORT":
                    handleBulkProductImport(job);
                    break;
                    
                case "REPORT_GENERATION":
                    handleReportGeneration(job);
                    break;
                    
                case "EMAIL_CAMPAIGN":
                    handleEmailCampaign(job);
                    break;
                    
                default:
                    throw new IllegalArgumentException("Unknown job type: " + job.getJobType());
            }
            
        } catch (Exception e) {
            log.error("Job {} failed", job.getJobId(), e);
            asyncJobService.failJob(job.getJobId(), e.getMessage());
            
        } finally {
            TenantContextHolder.clear();
        }
    }
    
    private void handleBulkProductImport(AsyncJob job) {
        // Extract input
        BulkImportRequest request = JsonUtils.fromJson(
            job.getInputParams(), 
            BulkImportRequest.class
        );
        
        List<ProductData> products = request.getProducts();
        int totalItems = products.size();
        int processedItems = 0;
        int failedItems = 0;
        
        asyncJobService.updateProgress(job.getJobId(), 0, totalItems);
        
        // Process in batches
        for (int i = 0; i < products.size(); i++) {
            try {
                ProductData productData = products.get(i);
                productService.createProduct(productData.toProduct());
                processedItems++;
                
                // Update progress every 10 items
                if (i % 10 == 0) {
                    asyncJobService.updateProgress(job.getJobId(), processedItems, totalItems);
                }
                
            } catch (Exception e) {
                log.error("Failed to import product at index {}", i, e);
                failedItems++;
            }
        }
        
        // Complete job
        BulkImportResult result = new BulkImportResult(
            totalItems, processedItems, failedItems
        );
        
        asyncJobService.completeJob(job.getJobId(), result);
    }
    
    private void handleReportGeneration(AsyncJob job) {
        // Generate report logic
        // ...
        asyncJobService.completeJob(job.getJobId(), reportResult);
    }
```

```typescript
// src/hooks/useWebSocket.ts

import { useEffect, useRef, useState } from 'react';
import SockJS from 'sockjs-client';
import { Client, IMessage } from '@stomp/stompjs';
import authService from '../services/authService';

export function useWebSocket<T>(topic: string) {
  const [message, setMessage] = useState<T | null>(null);
  const [isConnected, setIsConnected] = useState(false);
  const clientRef = useRef<Client | null>(null);
  
  useEffect(() => {
    const tenantId = authService.getTenantId();
    if (!tenantId) return;
    
    const socket = new SockJS(`${process.env.REACT_APP_WS_URL}/ws`);
    const client = new Client({
      webSocketFactory: () => socket,
      connectHeaders: {
        Authorization: `Bearer ${localStorage.getItem('access_token')}`,
      },
      onConnect: () => {
        console.log('WebSocket connected');
        setIsConnected(true);
        
        // Subscribe to tenant-specific topic
        client.subscribe(`/topic/${tenantId}/${topic}`, (message: IMessage) => {
          const data = JSON.parse(message.body) as T;
          setMessage(data);
        });
      },
      onDisconnect: () => {
        console.log('WebSocket disconnected');
        setIsConnected(false);
      },
      onStompError: (frame) => {
        console.error('WebSocket error:', frame);
      },
    });
    
    client.activate();
    clientRef.current = client;
    
    return () => {
      client.deactivate();
    };
  }, [topic]);
  
  return { message, isConnected };
}
```

## Summary

This guide provides a complete blueprint for building a production-ready multitenant SaaS application with:

### Core Components

1. **Two-Tier Database Architecture**
   - Platform DB: Tenant registry, billing, subscriptions, feature flags
   - Consumer DB: Tenant business data (users, products, orders, invoices)

   - Automatic tenant isolation via Hibernate filters

### Key Architectural Decisions

**Database Strategy:**
- Use **Platform DB + Shared Consumer DB** for most SaaS applications (100s-1000s tenants)
- Use **Database-per-tenant** only for large enterprise customers (< 50 tenants)
- Hybrid approach: shared for small/medium tenants, dedicated for enterprise

**API Design:**
- **Synchronous** for reads and simple writes (< 1 sec)
- **Asynchronous** for bulk operations, external API calls (> 5 sec)
- **Event-driven** for decoupled microservices and side effects

**Security Model:**
- Tenant ID in JWT claims (immutable, signed)
- ThreadLocal context (set once per request, always cleared)
- Hibernate filters (automatic tenant_id in WHERE clause)
- Row-level security (database-level enforcement)
- Service-layer validation (defense in depth)

**Scalability:**
- Horizontal scaling: API pods scale independently
- Worker scaling: based on queue depth
- Database scaling: read replicas, connection pooling
- Caching: Redis for tenant config, API responses

### Data Flow Summary

```text
Request Flow (Sync API):
User → JWT → API Gateway → Spring Boot → Tenant Filter → Database → Response
                                ↓
                         TenantContextHolder
                                ↓
                         Hibernate Filter (tenant_id = ?)
                                ↓
                         SELECT * FROM products WHERE tenant_id = 'tenant-123'

Request Flow (Async API):
User → JWT → API Gateway → Spring Boot → Job Created (202 Accepted)
                                              ↓
                                         Kafka Event
                                              ↓
                                         Worker Service
                                              ↓
                                         Process Job
                                              ↓
                                    Webhook + WebSocket Notification

Event Flow:
Action → Domain Event → Kafka → Multiple Consumers (Email, Inventory, Analytics)
```

### Critical Implementation Patterns

1. **Idempotency**: Use idempotency keys for all write operations
2. **Outbox Pattern**: Reliable event publishing (DB write + event in same transaction)
3. **Circuit Breaker**: Isolate tenant failures
4. **Rate Limiting**: Per-tenant quotas
5. **Retry with Backoff**: For webhooks and external APIs
6. **Dead Letter Queue**: For failed messages requiring manual intervention
7. **Reconciliation Jobs**: Periodic health checks for stuck jobs

### Common Pitfalls to Avoid

1. **Forgetting to clear TenantContext** → Memory leaks, cross-tenant data exposure
2. **No defense in depth** → Single point of failure in security
3. **Synchronous APIs for long operations** → Timeouts, resource exhaustion
4. **No retry mechanism** → Lost events, inconsistent state
5. **Missing audit logs** → Cannot debug production issues
6. **No tenant-level metrics** → Cannot identify noisy neighbors
7. **Hardcoded tenant logic** → Not scalable, difficult to maintain
